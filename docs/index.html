⚡ My Nudge — Personal Dashboard
Your personal nudge page lives on your own computer and is only visible to you. It pulls your email, calendar, Slack mentions, and Asana tasks into one checklist.

Setup (one time)

  1. Clone the repo: git clone <repo-url> ~/nudge-skills
  2. Copy the skill files to your global Claude Code commands folder:
    cp ~/nudge-skills/.claude/commands/* ~/.claude/commands/
  3. Copy the example config and fill it in:
    cp ~/nudge-skills/nudge-config.example.md ~/nudge/nudge-config.md
    Open ~/nudge/nudge-config.md and fill in your name, email, role, and Asana project GID.
  4. Open Claude Code and run /nudge. Your personal dashboard generates at ~/nudge/index.html.

Run /nudge any time to refresh your dashboard. Tell Claude to modify which sources it searches — it reads your config file.
